## Quick Reference

- **Setup**: `uv sync`
- **Run Pipeline**: `uv run python -m main --config configs/mvp.yaml`
- **Lint**: `uv run flake8 .`
- **Build Docs**: `uv run mkdocs build --strict`
- **Serve Docs**: `uv run mkdocs serve`
